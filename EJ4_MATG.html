Lenguajes de Programación - MATG

La programación consiste en especificar una estructura formal de instrucciones interpretables por un procesador para la resolución de problemas computacionales.

JavaScript - MATG

JavaScript es un lenguaje de programación interpretado, orientado a objetos y multitradición, fundamental para dotar de dinamismo e interactividad al cliente web.

TypeScript - MATG

TypeScript es un superconjunto tipado de JavaScript que compila a JavaScript puro, añadiendo tipado estático y análisis en tiempo de compilación.
