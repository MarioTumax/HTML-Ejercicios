MATG - Maquetación Adaptativa y Accesibilidad Web

El Diseño Web Responsivo (RWD) es una técnica de maquetación que ajusta dinámicamente la interfaz gráfica de usuario (GUI) al área de visualización (*viewport*) del dispositivo. Mediante el uso de reglas de estilo condicionales (*Media Queries*), se reorganiza el contenido para dispositivos móviles, tabletas y monitores de escritorio.

La accesibilidad web (WAI-ARIA) es esencial para garantizar que las tecnologías digitales sean inclusivas. Implementar semántica HTML adecuada permite que tecnologías asistivas, como los lectores de pantalla, interpreten correctamente la jerarquía estructural y los elementos interactivos del documento.

La manipulación eficiente de la estructura lógica del documento mediante JavaScript y hojas de estilo optimizadas evita los repintados (*repaint*) y reordenamientos (*reflow*) innecesarios en el motor de renderizado del navegador, manteniendo una tasa constante de fotogramas por segundo durante la interacción.
